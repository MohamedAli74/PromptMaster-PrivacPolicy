Prompt Master

Privacy Policy

Last updated: May 2026

Prompt Master is a Chrome extension that scores and expands AI prompts in real time. This policy explains exactly what data the extension touches, where it goes, and what you control.

What data is collected

Prompt Master reads the text you type into AI chat platforms (ChatGPT, Claude, Gemini) solely to score and expand your prompts. This text is processed locally in your browser and, when you click the Magic Wand, sent to the AI provider you have configured.

We do not collect, store, or transmit any prompt text to our own servers. We have no servers.

Where your data goes

When you use the Magic Wand expansion feature, your prompt is sent directly from your browser to the API endpoint of the provider you selected in Settings:

  • Groq — sent to api.groq.com using your own API key

Your prompt travels directly from your browser to the provider. Prompt Master sits in the middle only to format the request — it does not log, cache, or forward your data.

Each provider's own privacy policy governs how they handle requests. Groq's policy is available at groq.com/privacy-policy.

What is stored locally

Prompt Master stores the following in chrome.storage.sync, which is synced to your signed-in Google account across devices:

  • Your API key for the configured provider
  • Your preferences (automatic linting on/off)

This data never leaves your Google account sync. Prompt Master cannot read it from any server — only the extension itself, running in your browser, can access it.

Your control

You can remove all stored data at any time:

  • Open Prompt Master Settings → Engine → clear the API key field → Save
  • Or uninstall the extension — Chrome removes all associated storage on uninstall

Permissions

Prompt Master requests the following Chrome permissions:

  • storage — to save your API key and preferences locally
  • activeTab — to inject the linter UI into the active AI chat tab
  • Host access to chatgpt.com, claude.ai, gemini.google.com, and api.groq.com — to detect the chat input and send expansion requests

No other permissions are requested or used.

Changes to this policy

If this policy changes materially, the "Last updated" date above will reflect the change. Continued use of the extension after an update constitutes acceptance.

Prompt Master is built by MASSS. This extension has no affiliation with ChatGPT, Claude, Gemini, or Groq.
